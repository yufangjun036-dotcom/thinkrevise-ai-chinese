# 匿名真实文章收集与评测说明

## 目标

内部构造案例只能证明已知边界没有回归，不能估算系统面对真实学生文章时的总体表现。下一轮目标是收集 10–15 篇自愿提供、已去除个人信息的真实英文草稿，并由人工先独立标注，再运行系统。

## 收集规则

- 只接受作者明确同意用于本项目测试的文章。
- 删除姓名、学号、邮箱、课程编号、教师姓名、单位名称及可识别经历。
- 不收集评分、健康、身份、纪律处分或其他敏感信息。
- 每篇建议 100–600 词，并覆盖不同英语水平与学科背景。
- 至少包括：3 篇基本正确文本、3 篇少量错误文本、3 篇错误较多文本、2 篇较长文本和 2 组第二稿。
- 文章不得直接提交到 GitHub；本地文件名固定为 `external-samples.local.json`，已由 `.gitignore` 排除。

## 正确顺序

1. 作者同意并完成匿名化。
2. 评审者在不看产品输出的情况下标注客观错误和学术建议。
3. 冻结人工标注。
4. 才运行 ThinkRevise AI，并保存匿名结果。
5. 分别计算客观问题和学术建议指标；不把“建议更多”当成更准确。
6. 对所有分歧逐项裁决，失败案例加入回归集。

## 本地使用

复制 `external-samples.example.json` 为 `external-samples.local.json`，填写实际样本。运行：

```bash
EXTERNAL_SAMPLE_FILE=benchmarks/accuracy/external-samples.local.json npm run samples:validate
```

验证只检查同意、匿名化、长度、编号和基本覆盖，不会调用 API，也不会把文章上传或写入报告。
