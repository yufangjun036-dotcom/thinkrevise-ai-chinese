# Image replacement guide

The visual system can accept user-selected images later without changing the learning flow. Final images should support the learning context rather than decorate empty space.

## Suggested placements

1. Optional home-page feature image: a real university learner reviewing a draft, landscape crop, approximately 1600 x 1000.
2. Optional writing-topic thumbnail set: one consistent image style for the four topic choices.
3. Optional portfolio screenshot: a clean capture of the working revision screen after the Chinese prototype is stable.

## Asset record

For every final image, record:

| Filename | Creator/source | Source URL | Licence/permission | Date accessed | Chinese/English parity checked |
| --- | --- | --- | --- | --- | --- |
| Pending | Pending | Pending | Pending | Pending | Pending |

Do not add an image until its source and permission are known. The English copy must reuse the same filename, crop, dimensions, and placement.
