### 续测促成的修复

- 正确的进行时/动名词 relying on 被机械规则误报：移除无上下文依据的规则。
- Does it help / How can it improve 等疑问句被短模式误报：加入助动词倒装边界。
- 复核否定的规则候选被后续校验补回：改为规则与旧反馈先复核，后续不补回；最终稿只执行保留的修正。
- 通用“语法”标题导致 noun/句子连接错误被漏分组：结合反馈中的明确不可数名词、独立分句证据规范类别。
- informations 与 many informations 重复：保留同时修正数量词和名词的完整建议。
- 连写句的箭头只引用前半句，却在替换中又放入原有后半句：拒绝会重复未改动后缀的替换。
- 经验性无条件普遍断言与逻辑定义需区分；新增教学普遍有效与正方形定义的反向对照，不能见到 always 就报错。
