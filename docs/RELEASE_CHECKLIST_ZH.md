# ThinkRevise AI 中文版发布验收清单

更新日期：2026-09-08

这份清单是每次准备对外发布时的固定入口。自动测试通过只说明代码、数据和已建立的回归规则没有倒退；手机操作、真实 AI 结果和陌生访客体验仍需要人工确认。

## 自动发布门

- 运行 `npm run verify:release`。
- 必须全部通过：代码检查、学习数据、输入限制、中文界面、学习护栏、安全与费用保护、36 例准确率数据集、正式构建、隔离演示服务器上的三档 API 与第二稿复检、异常恢复和发布清单完整性。
- 自动规则会确认窄屏断点和单列排列代码仍然存在，但不能代替下面两种精确尺寸与实体手机的人工操作。
- 默认命令不得调用付费 API；真实 AI 测试必须由测试者明确启动。
- 保存日期、版本、通过项目和未完成项目。任何失败都不能忽略或标记为稳定版。

## 桌面人工验收

- 首页两条入口、返回、重新开始和隐私说明链接均可使用。
- 主题写作四个预设方向与自定义方向均可进入完整流程。
- 重新抽词后，再次填入的演示初稿包含本轮全部目标词，并保留合理的练习错误。
- 每个目标词直接显示中文含义，展开后仍有搭配和例句。
- 三档帮助程度严格保持差异，红色波浪线、问题导航和旁边提示均能对应原文位置。
- 第二稿独立复检，已修正、仍存在和新产生的问题不会因微小编辑而异常消失或增加。
- 刷新、返回、快速双击、服务失败和格式错误不会清空学习者文章或造成无限加载。

## 手机人工验收

- 在 390×844 和 430×932 两种尺寸完整走完主题写作和学术英文修改主流程。
- 页面不出现横向滚动；按钮、输入框、目标词和问题卡无需缩放即可阅读与点击。
- 桌面双列内容在窄屏安全变为上下排列，版本标签保持清楚。
- 红线提示在触屏点击后可以固定、关闭，并且不会挡住整段文章或主要按钮。
- 软键盘出现时当前输入框、字数提示和继续按钮仍可到达。
- 发布前至少使用一台真实手机和无痕窗口复测，不能只依赖电脑模拟尺寸。

## 真实 AI 验收

- 使用专门测试文章分别验证主题写作、自定义主题和学术英文修改三档模式。
- 对明显拼写、语法、时态、学术表达、结构和论证问题人工核对，不以“问题数量多”代替正确率。
- 运行经过审核的完整基准时必须显式开启真实测试；记录模型、日期、耗时、费用和报告位置。
- 第二名学术英语评审者尚未独立复核金标准前，不对外宣称“基本没有错误”或“全面正确”。
- 真实 AI 超时、余额不足或返回异常时，页面必须明确标记备用演示反馈，不能冒充实时结果。

## 隐私与费用

- `.env.local`、生产密钥、真实文章和个人信息均不进入 Git。
- 生产环境使用独立项目和独立密钥，配置项目硬性消费上限及提醒。
- 自动充值保持关闭，或设置用户明确接受的绝对上限。
- 多实例公开部署前必须使用共享限流存储或平台级防火墙，不能只依赖单实例内存计数。
- 用无痕窗口确认隐私说明可见，页面准确说明发送内容、标签页恢复、应用不建立文章数据库和服务商保留边界。

## GitHub 前检查

- 检查暂存文件列表和差异，不提交密钥、日志、私人文章、临时截图或构建目录。
- README 必须包含项目目的、三档功能、真实 AI 架构、运行方法、测试证据、隐私、安全限制和当前状态。
- 补充许可证、最终截图或短演示、架构图和可复现的安装步骤。
- 用户明确批准后才能提交、改名、创建远程仓库或推送。

## 阻断发布的情况

- 任意自动发布门失败。
- 明显语言错误漏报、正确表达被高置信度误报、最终稿改变原意或虚构证据／引文。
- 第二稿微小修改导致无关问题异常消失或增加。
- 手机主流程无法完成、文字被截断、横向溢出或提示无法关闭。
- 密钥可能暴露、费用上限未配置、隐私说明与实际行为不一致。
- 公开链接只能在开发者本人登录或本机环境中工作。
