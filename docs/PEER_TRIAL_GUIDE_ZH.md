# ThinkRevise AI：5 分钟同伴试用引导

## 试用目标

在五分钟内，让同伴亲自完成一次“初稿—AI 诊断—自己修改—版本比较—反思”的核心学习循环，而不是观看操作录像。

## 主试用任务

1. 打开首页，选择“学术英语修改”。
2. 选择“自主诊断修改”。
3. 点击“继续填写初稿”，再点击“填入演示初稿”。
4. 填写中心观点，并选择本轮希望 AI 重点帮助的方向。
5. 点击“分析并定位文章问题”。
6. 浏览不同类型的问题与正确用法。
7. 进入修改页，观察原稿中的红色问题标记。
8. 修改右侧第二稿中的至少一句话并提交。
9. 比较原稿、第二稿与最终规范版本，写一句反思。

## 引导者时间提示

| 时间 | 引导内容 |
| --- | --- |
| 0:00–0:30 | 说明任务目标，提醒不要输入姓名、学号或真实敏感作业内容 |
| 0:30–1:20 | 同伴选择模式并使用演示初稿 |
| 1:20–2:00 | 同伴完成 AI 前自我检查 |
| 2:00–3:20 | 同伴阅读不同类型的问题与修改方向 |
| 3:20–4:15 | 同伴修改一句并查看前后版本 |
| 4:15–5:00 | 同伴完成反思并填写 Google Form |

## 备用方案

- 若没有 API 密钥：系统自动显示“演示反馈模式”，核心交互保持可用。
- 若实时 AI 请求失败：系统自动回退到演示反馈并显示说明。
- 若同伴没有自己的英文：使用“填入演示初稿”。
- 若时间不足：只阅读三种不同类型的问题，但仍让同伴亲自修改一句。
- 若浏览器刷新：重新进入主试用任务；不要求注册或恢复账号。

## 观察记录

引导者只记录，不在同伴卡住前立即解释：

- 能否在 20 秒内找到正确入口；
- 是否理解三种帮助程度的差异；
- 是否知道为什么按钮暂时不能继续；
- 是否能根据红色下划线找到原文中的问题；
- 是否能理解“局部示例”和“完整改写”的差异；
- 是否注意到演示／实时 AI 标签和原意风险提示。

## Google Form 建议问题

1. 哪一步最容易理解？为什么？
2. 哪一步让你犹豫或困惑？
3. AI 反馈是否帮助你自己思考，而不只是给出答案？
4. 你是否理解“学习模式”和“编辑模式”的差异？
5. 如果只能改变一件事，你会建议改变什么？
6. 你是否愿意在真实英文写作中使用该工具？为什么？
