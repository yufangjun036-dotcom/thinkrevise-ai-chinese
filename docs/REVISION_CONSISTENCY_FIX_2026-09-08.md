# 第二稿矛盾反馈修复（2026-09-08）

## 触发样例与根因

用户仅把 `students is` 改为 `students are`，复检却同时显示“已修正”和“students are using AI：无；此处已正确”。离线调用实际路由函数复现：无问题表述过滤器漏判，比较器再将新引文归类为 changed，前端直接展示并计数。

## 本地修改

- 扩充中英文明确无问题表述识别，保留有具体修改或转折指出其他真实错误的反馈。
- 比较阶段再次排除无问题记录及无法定位的引文；按类别与引文匹配旧问题。
- 同类错误在修改后的近似句中仍存在时，不再同时将旧问题列为未检出。
- 不再仅凭旧短语仍存在就搬回旧问题：客观语言错误要求所在句未变，论证等依赖上下文的问题由当前复检判断。纯格式变化及尾部误加一个字母保留原问题保护。
- 最终去重、截断之后，从实际展示列表生成三类数量；修复前缀相同的不同词被去重的问题。
- 页面和复制记录将“已经修正”改为“本轮未再检出”，避免把未检出包装为确定正确。保留原响应字段名兼容既有类型。

## 验证与边界

新增 `scripts/check-revision-consistency.mjs`，直接加载路由实际函数并注入合成模型结果，覆盖矛盾反馈、三种模式、无修改、单处修正、仍错、新错、上下文改变、清洁稿、重复及超过展示上限等情况。该测试纳入 check:safeguards 和发布检查。

本地构建、API 回归、边界恢复、演示稿验证通过。所有测试不发送付费模型请求。

这不是全面准确率认证：未取得触发事件的原始模型响应；无问题表述检测及句子匹配仍属于启发式校验。多位置改写、复杂上下文和真实模型输出需要持续评测。当前最终稿生成逻辑未重构，仍需核对事实和原意。

修改尚未提交、推送或公开部署；线上验证需发布新版本后进行。
